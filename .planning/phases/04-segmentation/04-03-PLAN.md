Replace the stub `pipeline/tasks/generate_cutouts.py` with the full implementation.

**Module structure:**

```
generate_cutouts.py
├── _extract_cutout_data(fits_data, wcs_object, centroid_x, centroid_y, bbox, padding_fraction) -> Cutout2D
├── _create_stretched_png(cutout_data, output_path) -> None
├── _create_raw_png(cutout_data, output_path) -> None
├── _create_fits_cutout(cutout_2d, output_path) -> None
├── _upload_cutout_files(s3_client, observation_uuid_hex, object_uuid_hex, temp_dir) -> str
├── generate_cutouts(self, segmentation_result: dict) -> dict  # Celery task
```

**`_extract_cutout_data(fits_data, wcs_object, centroid_x, centroid_y, bbox, padding_fraction=0.1) -> Cutout2D`:**
Use `astropy.nddata.Cutout2D` to extract a WCS-preserving cutout.
1. Compute padded size from bounding box: `width = int((bbox['xmax'] - bbox['xmin']) * (1 + 2 * padding_fraction))`, same for height. Minimum size 16px in each dimension to avoid degenerate cutouts.
2. `cutout = Cutout2D(fits_data, position=(centroid_x, centroid_y), size=(padded_height, padded_width), wcs=wcs_object, mode='partial', fill_value=0.0)`
3. Return the Cutout2D object (has `.data` and `.wcs` attributes).

**`_create_stretched_png(cutout_data, output_path)`:**
Create auto-stretched PNG using asinh stretch (same as tile.py normalization).
1. Handle NaN/inf: `data = np.nan_to_num(cutout_data, nan=0.0, posinf=0.0, neginf=0.0)`.
2. Compute ZScale limits on the cutout itself: `vmin, vmax = ZScaleInterval().get_limits(data)`.
3. Linear rescale + asinh stretch + uint8: same normalization pipeline as tile.py `_normalize_chunk`.
4. Save as PNG via `PIL.Image.fromarray(uint8_data, mode='L').save(output_path)`.

**`_create_raw_png(cutout_data, output_path)`:**
Create raw linear PNG (no stretch, just linear mapping).
1. Handle NaN/inf.
2. Simple min-max linear scaling to [0, 255]: `data_clipped = np.clip(data, np.nanpercentile(data, 1), np.nanpercentile(data, 99))`, then `((data_clipped - vmin) / (vmax - vmin) * 255).astype(np.uint8)`.
3. Save as PNG.

**`_create_fits_cutout(cutout_2d, output_path)`:**
Create a FITS file with the cutout data and preserved WCS.
1. `hdu = fits.PrimaryHDU(data=cutout_2d.data, header=cutout_2d.wcs.to_header())`
2. `hdu.writeto(output_path, overwrite=True)`

**`_upload_cutout_files(s3_client, observation_uuid_hex, object_uuid_hex, temp_dir) -> str`:**
Upload all cutout files for one object to MinIO segmentation bucket.
S3 key structure: `{observation_uuid}/{object_uuid}/`
Files to upload:
- `cutout_stretched.png` — auto-stretched display version (ContentType: image/png)
- `cutout_raw.png` — raw linear version (ContentType: image/png)
- `cutout.fits` — FITS with WCS (ContentType: application/fits)

Return the S3 prefix string: `{observation_uuid}/{object_uuid}/`

**`generate_cutouts(self, segmentation_result: dict) -> dict` (Celery task):**
Decorated with `@celery_app.task(bind=True, autoretry_for=(ConnectionError, TimeoutError), retry_backoff=True, max_retries=3, acks_late=True)`.

1. Extract `observation_uuid_hex`, `fits_s3_keys`, `object_uuids`, `masks_generated` from `segmentation_result`.
2. Create `ProcessingStep(step_name="generate_cutouts", step_status=StepStatus.running)`.
3. If no objects (empty `object_uuids`), mark step completed with `{"cutouts_generated": 0}`, set observation `pipeline_status = PipelineStatus.completed`, return early.
4. Download first FITS from MinIO.
5. Open FITS, get 2D data and WCS (same pattern as detect_sources).
6. Fix byte order for float32.
7. Query AstronomicalObject records by observation_uuid.
8. Create temp directory for cutout files.
9. For each object:
   a. Extract cutout using `_extract_cutout_data` with the object's bounding_box_pixels and centroid.
   b. Create 3 files in temp dir: `_create_stretched_png`, `_create_raw_png`, `_create_fits_cutout`.
   c. Upload to MinIO: `_upload_cutout_files`.
   d. Update `AstronomicalObject.cutout_s3_prefix` in DB.
   e. Clean up temp files for this object (don't accumulate).
10. For objects whose bounding box extends beyond the image boundary (edge objects), use `Cutout2D(mode='partial', fill_value=0.0)` which fills missing pixels with zeros.
11. Update ProcessingStep to completed with metadata: `{"cutouts_generated": N, "total_bytes_uploaded": B, "stretched_png_count": N, "raw_png_count": N, "fits_cutout_count": N}`.
12. **CRITICAL: Set observation pipeline_status to PipelineStatus.completed.** This is the final task in the chain. Query Observation record and update `pipeline_status = PipelineStatus.completed`. This is the status that tile.py used to set — now it's here at the true end of the pipeline.
13. Commit and return dict: `{"observation_uuid": observation_uuid_hex, "cutouts_generated": N, "status": "completed"}`.
14. On exception: mark ProcessingStep failed, mark Observation failed, re-raise.
15. Finally: clean up temp dir, close DB session.

**Memory management:** Process cutouts one at a time, not batched. Each cutout is small (bounding box + 10% padding), so memory is not a concern per-object, but processing thousands sequentially without cleanup would accumulate temp files.

**Batch DB updates:** Flush after every 100 objects to avoid accumulating too many pending changes in the SQLAlchemy session.

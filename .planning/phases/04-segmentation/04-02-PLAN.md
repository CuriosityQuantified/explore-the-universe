**Module structure:**

```

├── _compute_kron_photometry(data_sub, bkg, objects) -> (flux, fluxerr)

├── detect_sources(self, tile_result: dict) -> dict  # Celery task
```

**`_fix_byte_order(data: np.ndarray) -> np.ndarray`:**
SEP requires native byte order. FITS is big-endian. Convert: if `data.dtype.byteorder` not in `('=', '<', '|')`, call `data.byteswap().newbyteorder()`. Always cast to float32.

**`_detect_sources_in_array(data: np.ndarray, settings: Settings) -> tuple[np.ndarray, sep.Background]`:**
Run SEP background estimation and source extraction on a 2D float32 array.
1. `bkg = sep.Background(data, bw=settings.segmentation_background_box_size, bh=settings.segmentation_background_box_size, fw=3, fh=3)`
2. `data_sub = data - bkg.back()`
3. `objects = sep.extract(data_sub, thresh=settings.segmentation_detection_threshold_sigma, err=bkg.globalrms, minarea=settings.segmentation_min_area_pixels, deblend_nthresh=settings.segmentation_deblend_nthresh, deblend_cont=settings.segmentation_deblend_contrast)`
4. Return `(objects, bkg, data_sub)`.

**`_compute_kron_photometry(data_sub, bkg, objects)`:**
Compute Kron radius photometry for better flux/SNR estimates:
1. `kronrad, krflag = sep.kron_radius(data_sub, objects['x'], objects['y'], objects['a'], objects['b'], objects['theta'], 6.0)`
2. Handle edge case where kronrad might be 0 or NaN — set minimum kronrad to 1.0.
3. `flux, fluxerr, flag = sep.sum_ellipse(data_sub, objects['x'], objects['y'], objects['a'], objects['b'], objects['theta'], 2.5 * kronrad, err=bkg.globalrms, subpix=1)`
4. Return `(flux, fluxerr)`.

**`_assign_confidence_tiers(objects, flux, fluxerr, settings)`:**
Compute SNR = flux / fluxerr (handle division by zero: where fluxerr == 0, set SNR to 0).
Assign tiers:
- SNR >= `settings.segmentation_snr_high_threshold` (10.0) -> "high"
- SNR >= `settings.segmentation_snr_medium_threshold` (3.0) -> "medium"
- Below -> "low"
Return array of tier strings and array of SNR values.

**`_flag_edge_detections(objects, image_height, image_width, sub_region_origin_x, sub_region_origin_y, sub_region_width, sub_region_height)`:**
An object is "edge" if its bounding box (computed from `objects['x'] +/- 3*objects['a']` and similar for y/b, rotated by theta — or simpler: use `xmin/xmax/ymin/ymax` from SEP if available, else compute from centroid +/- 3*kron_radius) touches within 5 pixels of the sub-region boundary OR the full image boundary. Return boolean array.

Since SEP extract doesn't return xmin/xmax directly, compute bounding box from ellipse params: approximate as `x - 3*a` to `x + 3*a` (semi-major axis extent). Mark as edge if any extent is within 5px of (0, sub_region_width) or (0, sub_region_height) or the full image edges.

**`_extract_sub_regions(image_height, image_width, region_size, overlap_fraction) -> list[tuple[int, int, int, int]]`:**
Generate list of `(y_start, y_end, x_start, x_end)` tuples for tiling with overlap.
- Overlap in pixels: `int(region_size * overlap_fraction)`
- Stride: `region_size - overlap_pixels`
- Last region may extend to image edge (no need for exact sizing)
- Return empty list if image is smaller than region_size (full-field detection is sufficient)

**`_run_multi_scale_detection(fits_data, wcs_object, observation_uuid, database_session, settings) -> list[uuid.UUID]`:**
The core multi-scale loop. Returns list of created AstronomicalObject UUIDs.

Scale 1: Full field
- Run `_detect_sources_in_array` on full fits_data
- Compute photometry, tiers, edge flags
- For each detection: convert pixel centroid to RA/Dec via `wcs_object.pixel_to_world(x, y)` (returns SkyCoord)
- Create `AstronomicalObject` records with `detection_scale_level="full_field"`
- Batch insert (add_all) and flush (not commit — caller commits)

Scale 2: Sub-regions (1024px with 20% overlap)
- Skip if image is smaller than 1.5x the sub-region size in both dimensions
- Generate sub-regions via `_extract_sub_regions`
- For each sub-region:
  - Slice fits_data[y_start:y_end, x_start:x_end]
  - Run detection on the sub-array
  - Convert pixel coords from sub-region-local to full-image coords: `x_global = x_local + x_start`, `y_global = y_local + y_start`
  - Compute WCS from global pixel coords
  - Flag edges relative to sub-region boundary AND full image boundary
  - Create AstronomicalObject records with `detection_scale_level="sub_region"`

Scale 3: Sub-sub-regions (256px with 20% overlap)
- Only process sub-regions that had detections (skip empty areas)
- Same pattern as Scale 2 but with smaller region_size from `settings.segmentation_sub_sub_region_size`
- `detection_scale_level="sub_sub_region"`

For ALL objects at ALL scales: store `pixel_centroid_x`, `pixel_centroid_y`, `bounding_box_pixels` (as JSON dict `{"xmin": N, "ymin": N, "xmax": N, "ymax": N}` in full-image coords), `detection_signal_to_noise_ratio`, `detection_confidence_tier`, `detection_scale_level`, `is_edge_detection`.

**`_get_sam_processor()` (lazy singleton):**
Module-level `_sam_processor = None`, `_sam_available = None`.
- If `_sam_available is False`, return None immediately.
- If `_sam_processor is not None`, return it.
- Try: `import torch`, check `torch.cuda.is_available()`. If no CUDA, log warning, set `_sam_available = False`, return None.
- Try: `from sam3 import build_sam3_image_model; from sam3.model.sam3_image_processor import Sam3Processor`.
- Build model with `bpe_path=settings.sam3_bpe_path` if non-empty, `enable_inst_interactivity=True`.
- Create processor, set `_sam_available = True`, return processor.
- On any Exception: log warning with the exception message, set `_sam_available = False`, return None.

**`_fits_to_sam_rgb(fits_data, vmin, vmax) -> np.ndarray`:**
Convert FITS float32 data to SAM-compatible uint8 RGB.
1. Handle NaN/inf: `data = np.nan_to_num(fits_data, nan=0.0, posinf=0.0, neginf=0.0)`
2. Apply ZScale + asinh stretch (same as tile.py normalization — reuse the same approach):
   - Linear rescale to [0,1]: `np.clip((data - vmin) / (vmax - vmin), 0, 1)` if vmax > vmin else zeros
   - Apply `AsinhStretch(a=0.1)`
   - Scale to [0, 255] uint8
3. Replicate single channel to 3-channel RGB: `np.stack([uint8_data, uint8_data, uint8_data], axis=-1)`
4. Return shape (H, W, 3) uint8 array.

If the image is larger than 1024x1024, do NOT resize here — the task processes sub-regions that are already <=1024px. If a region is larger (e.g., full-field pass on a large image), SAM will be skipped for that region and SEP elliptical masks used instead. Log this decision.

**`_generate_sam_masks(processor, image_rgb, detections) -> list[np.ndarray]`:**
Generate SAM masks for a batch of detections.
1. `from PIL import Image; pil_image = Image.fromarray(image_rgb)`
2. `inference_state = processor.set_image(pil_image)`
3. For each detection (or batched via `predict_inst_batch` if available):
   - Point prompt: `point_coords=[[det.pixel_centroid_x, det.pixel_centroid_y]]`, `point_labels=[1]`
   - Box prompt from bounding_box_pixels: `box=[xmin, ymin, xmax, ymax]`
   - Call `processor.model.predict_inst(inference_state, point_coords=..., labels=..., box=..., multimask_output=False)`
   - Extract best mask (highest score if multimask_output=True)
4. Return list of binary mask arrays (bool, shape H x W).

If batch processing via `predict_inst_batch` is available, prefer it for efficiency. Otherwise fall back to per-detection `predict_inst` calls.

Wrap all SAM calls in try/except — if SAM fails on a specific detection, log warning and fall back to elliptical mask for that detection.

**`_generate_elliptical_mask(image_shape, centroid_x, centroid_y, semi_major_a, semi_minor_b, theta_radians) -> np.ndarray`:**
Generate a binary elliptical aperture mask from SEP parameters.
1. Create coordinate grid: `y_grid, x_grid = np.ogrid[0:image_shape[0], 0:image_shape[1]]`
2. Apply rotation: compute rotated coordinates relative to centroid using theta.
3. Evaluate ellipse equation: `((x_rot / semi_major_a)**2 + (y_rot / semi_minor_b)**2) <= 1.0`
4. Use 3x Kron radius scaling for semi_major/semi_minor to capture full source extent (same as Kron aperture convention: `a * 2.5` for Kron radius).
5. Return boolean mask array.

Actually, use `2.5 * kron_radius` as the aperture scaling, matching the Kron photometry. But since Kron radius isn't directly available here, use `a * 3` and `b * 3` as a reasonable approximation for extended sources. Make this a constant `ELLIPSE_MASK_KRON_FACTOR = 3.0`.

**`_encode_mask_to_rle(binary_mask: np.ndarray) -> dict`:**
Encode binary mask to COCO RLE format.
1. `import pycocotools.mask as mask_util`
2. `fortran_mask = np.asfortranarray(binary_mask.astype(np.uint8))`
3. `rle = mask_util.encode(fortran_mask[:, :, np.newaxis])[0]`
4. `rle['counts'] = rle['counts'].decode('utf-8')` — bytes to str for JSON/JSONB storage
5. Return rle dict with `{'size': [H, W], 'counts': str}`.

**`_merge_boundary_masks(object_records, overlap_info, iou_threshold) -> list[UUID]`:**
Merge masks for objects that appear in overlapping sub-region zones.

Strategy: After all sub-region detections are complete, for objects that appear in the overlap zone between adjacent sub-regions:
1. Identify candidate pairs: objects from adjacent sub-regions whose bounding boxes overlap.
2. Compute IoU between their masks using `pycocotools.mask.iou()`.
3. If IoU >= `iou_threshold` (default 0.5), keep the detection with the higher SNR and discard (delete) the other.
4. Return list of deleted object UUIDs for logging.

This is a post-processing step that runs after all sub-region segmentation is complete. It operates on the database records, not in-memory arrays.

For simplicity: compute IoU using the RLE-encoded masks already stored in the database. `mask_util.iou()` works directly on RLE dicts.

**`segment_sam(self, detection_result: dict) -> dict` (Celery task):**
Decorated with `@celery_app.task(bind=True, autoretry_for=(ConnectionError, TimeoutError), retry_backoff=True, max_retries=3, acks_late=True)`.

1. Extract `observation_uuid_hex`, `fits_s3_keys`, `source_count`, `object_uuids` from `detection_result`.
2. Create `ProcessingStep(step_name="segment_sam", step_status=StepStatus.running)`.
3. If `source_count == 0`, mark step completed with metadata `{"masks_generated": 0, "method": "none", "reason": "no sources detected"}`, return early.
4. Download first FITS from MinIO (same pattern as detect_sources).
5. Open FITS, get 2D data and WCS.
6. Compute normalization params (vmin, vmax) using ZScaleInterval on a subsample — same approach as tile.py `_compute_normalization_parameters`.
7. Attempt SAM initialization: `processor = _get_sam_processor()`.
8. Determine method: `method = "sam3" if processor is not None else "sep_ellipse"`.
9. Query all AstronomicalObject records for this observation from the database (batch query by observation_uuid).
10. Process detections:

    - For sub-region and sub-sub-region detections: process region by region (extract the sub-region from FITS data, convert to RGB for SAM, generate masks for all detections in that region).
    - For full-field detections on small images (<= 1024px): convert entire image to RGB, run SAM.
    - For full-field detections on large images (> 1024px): use SEP elliptical masks (SAM can't handle >1024px input).
    - If method == "sep_ellipse": always use `_generate_elliptical_mask` from the SEP parameters stored in `bounding_box_pixels` and the original SEP ellipse params. 11. For each object: encode mask as RLE, update `segmentation_mask_rle` and `segmentation_method` in DB.
12. Run boundary mask merging: `_merge_boundary_masks(...)`.
13. Update ProcessingStep to completed with metadata: `{"masks_generated": N, "method": method, "merged_count": M, "deleted_duplicates": D}`.
14. Commit and return dict: `{"observation_uuid": observation_uuid_hex, "fits_s3_keys": fits_s3_keys, "object_uuids": [remaining uuids], "has_sam_masks": method == "sam3", "masks_generated": N}`.
15. On exception: mark failed, re-raise.
16. Finally: clean temp files, close DB session.

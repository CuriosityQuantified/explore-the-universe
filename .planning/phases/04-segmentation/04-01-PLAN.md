- `detection_scale_level = Column(String, nullable=True)` — "full_field", "sub_region", "sub_sub_region"
- `is_edge_detection = Column(Boolean, default=False, nullable=False)` — True if object touches image/sub-region boundary
- `pixel_centroid_x = Column(Float, nullable=True)` — SEP centroid X in image pixel coords
- `pixel_centroid_y = Column(Float, nullable=True)` — SEP centroid Y in image pixel coords
- `segmentation_method = Column(String, nullable=True)` — "sam3" or "sep_ellipse" (which method produced the mask)

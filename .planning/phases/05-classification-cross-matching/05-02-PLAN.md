**Main function: `cross_match_catalogs(self, cutout_result: dict) -> dict`**

1. Create `ProcessingStep(step_name="cross_match_catalogs", step_status=StepStatus.running)` at start
2. Extract `observation_uuid_hex` from `cutout_result["observation_uuid"]`
3. Query all `AstronomicalObject` records for this observation from DB
4. If no objects, create completed ProcessingStep and return early

5. **Compute pixel scale** from FITS WCS header:
   - Download first FITS file from MinIO (same `fits_s3_keys` recovery pattern as detect_sources -- check `cutout_result` dict first, fall back to download_fits ProcessingStep metadata)
   - Open with `astropy.io.fits`, get WCS from SCI extension (same `_find_sci_extension` pattern)
   - Compute `pixel_scale_arcsec_per_pixel = abs(wcs.wcs.cdelt[0]) * 3600` if cdelt exists, else `np.sqrt(wcs.wcs.cd[0,0]**2 + wcs.wcs.cd[1,0]**2) * 3600`
   - Close FITS and clean up temp file

6. **Cross-match each object against all 4 catalogs in parallel:**
   For each AstronomicalObject:
   - Compute adaptive search radius via `compute_search_radius_arcsec(obj.bounding_box_pixels, pixel_scale_arcsec_per_pixel)` using settings from config
   - Create `SkyCoord(ra=obj.sky_coordinate_ra_degrees, dec=obj.sky_coordinate_dec_degrees, unit='deg', frame='icrs')`
   - Use `concurrent.futures.ThreadPoolExecutor(max_workers=4)` to query all 4 catalogs in parallel (per user decision: no priority order, no early exit)
   - Each catalog query uses the client module from `pipeline/catalog_clients/`

7. **Store ALL matches** (per user decision: keep ALL matches from ALL catalogs):
   For each catalog result, for each match:
   - Create `CatalogCrossMatch` record with:
     - `object_uuid`: the AstronomicalObject's UUID
     - `catalog_name`: "simbad", "ned", "sdss", or "gaia"
     - `catalog_source_id`: from match dict
     - `angular_separation_arcseconds`: computed distance
     - `match_probability_score`: `1.0 / (1.0 + angular_separation_arcsec)` (simple inverse-distance confidence)
     - `raw_catalog_response`: full raw response dict as JSONB

8. **Update AstronomicalObject indexed fields** with "best" catalog match:
   - `catalog_object_name`: Use first SIMBAD match name, else NED, else SDSS objid, else Gaia source_id
   - `catalog_magnitude`: Use SIMBAD flux(V), else SDSS petroMag_r, else Gaia phot_g_mean_mag
   - `catalog_redshift`: Use SIMBAD redshift, else NED redshift, else SDSS z
   - `classified_object_type`: Use SIMBAD OTYPE, else NED Type, else SDSS class
   - `classification_source_catalog`: Which catalog provided the type

9. Batch DB flush every 50 objects (same pattern as generate_cutouts)
10. Create completed ProcessingStep with metadata: `{objects_processed, matches_found, catalogs_queried, catalogs_failed}`
11. Return dict: `{observation_uuid, objects_processed, total_matches, catalogs_queried: [...], status: "completed"}`

**Error handling:**
- On catalog failure after 3 retries: mark that catalog as "not_queried" per object (per user decision), continue with remaining catalogs
- On task-level exception: mark ProcessingStep as failed, mark Observation as failed, re-raise

**Performance note:** For observations with 100+ objects, consider batching SIMBAD queries using `batch_query_simbad()` from the simbad_client. NED will be the bottleneck (~2 queries/sec per object).

**pipeline/feature_extraction.py:**

Create `extract_feature_vector(cutout_data: np.ndarray | None, rle_mask: dict | None, sep_physical_properties: dict | None = None, gain: float = 1e5) -> dict`:

**Path A — statmorph path (cutout_data AND rle_mask both provided):**

1. Decode COCO RLE mask to binary mask using `pycocotools.mask.decode()` (same pattern as research example):
   ```python
   rle_copy = dict(rle_mask)
   if isinstance(rle_copy["counts"], str):
       rle_copy["counts"] = rle_copy["counts"].encode("utf-8")
   binary_mask = mask_util.decode(rle_copy).squeeze()
   ```

2. Create labeled segmentation map: `segmap = np.zeros_like(cutout_data, dtype=int); segmap[binary_mask > 0] = 1`

3. Run `statmorph.source_morphology(cutout_data, segmap, gain=gain)` to get morphological features

4. If statmorph returns results and `morph.flag < 2` (not catastrophically bad):
   Extract: concentration, asymmetry, smoothness, gini, m20, sersic_n, sersic_rhalf, ellipticity, flag, flag_sersic

5. If statmorph fails (`flag >= 2` or empty results), fall through to SEP fallback (Path B)

**Path B — SEP-only fallback (rle_mask is None, OR statmorph failed on Path A):**
   - Use `sep_flux`, `sep_a`, `sep_b`, `sep_theta` from `sep_physical_properties` to compute basic ellipticity = `1 - (b/a)`
   - Set statmorph-specific features (concentration, asymmetry, smoothness, gini, m20, sersic_n, sersic_rhalf) to NaN
   - This path is the ONLY path for objects detected by SEP but without SAM masks (per user decision: ML runs on EVERY object)

**Both paths then:**

6. Augment with SEP photometric features already in `physical_properties`:
   - `sep_flux`, `detection_signal_to_noise_ratio` (from AstronomicalObject column)

7. Handle NaN values: Replace any remaining NaN/Inf with -999.0 sentinel (classifier handles these via imputation)

8. Return full feature dict:
   ```python
   {
       "concentration": ..., "asymmetry": ..., "smoothness": ...,
       "gini": ..., "m20": ..., "sersic_n": ..., "sersic_rhalf": ...,
       "ellipticity": ..., "statmorph_flag": ..., "statmorph_flag_sersic": ...,
       "sep_flux": ..., "sep_a": ..., "sep_b": ...,
       "detection_signal_to_noise_ratio": ...,
       "feature_source": "statmorph" | "sep_fallback",
   }
   ```

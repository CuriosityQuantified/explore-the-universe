**pipeline/catalog_clients/__init__.py:**

Export `compute_search_radius_arcsec` utility function:

```python
def compute_search_radius_arcsec(
    bounding_box_pixels: dict,
    pixel_scale_arcsec_per_pixel: float,
    compact_source_radius_arcsec: float = 2.0,
    extended_source_scale_factor: float = 1.5,
    compact_source_threshold_arcsec: float = 5.0,
) -> float:
    """Adaptive search radius: compact ~2-3 arcsec, extended scales up proportionally.

    Per user decision: adaptive search radius based on object angular extent
    from segmentation. Compact sources ~2-3 arcsec, extended sources scale
    up proportionally.
    """
    bbox_width = bounding_box_pixels["xmax"] - bounding_box_pixels["xmin"]
    bbox_height = bounding_box_pixels["ymax"] - bounding_box_pixels["ymin"]
    angular_extent_arcsec = max(bbox_width, bbox_height) * pixel_scale_arcsec_per_pixel

    if angular_extent_arcsec < compact_source_threshold_arcsec:
        return max(compact_source_radius_arcsec, angular_extent_arcsec)
    else:
        return angular_extent_arcsec * extended_source_scale_factor
```

Create `query_simbad_region(coordinates: SkyCoord, radius_arcsec: float, timeout: int = 60) -> list[dict]`:
- Use `astroquery.simbad.Simbad()` instance
- Add VOTable fields: `otype`, `flux(V)`, `rvz_redshift`, `rvz_type`
- Call `simbad.query_region(coordinates, radius=radius_arcsec * u.arcsec)`
- Retry up to `max_retries` times with exponential backoff (per user decision: 3x retries)
- On final failure, return `[{"status": "not_queried", "catalog": "simbad", "error": str(e)}]`
- On success, convert astropy Table rows to list of dicts with keys: `catalog_source_id` (MAIN_ID), `object_type` (OTYPE), `ra_deg`, `dec_deg`, `angular_separation_arcsec` (computed from input coord), `magnitude` (FLUX_V), `redshift` (rvz_redshift), `raw_response` (full row as dict)
- Rate-limit-aware: No explicit throttle needed for vectorized queries (single request per batch)

Also create `batch_query_simbad(coord_list: list[SkyCoord], radius_list: list[float], batch_size: int = 20) -> dict[int, list[dict]]`:
- For batches <= batch_size: use vectorized `query_region(coord_list, radius=radius_list * u.arcsec)`
- For larger batches: chunk into groups of `batch_size` and process sequentially with 1-second sleep between chunks
- Return dict mapping object index to list of match dicts

**pipeline/catalog_clients/ned_client.py:**

Create `query_ned_region(coordinate: SkyCoord, radius_arcsec: float, max_retries: int = 3, rate_limit_delay: float = 0.5) -> list[dict]`:
- Use `astroquery.ipac.ned.Ned.query_region(coordinate, radius=radius_arcsec * u.arcsec)`
- NED has NO batch support -- per-object queries only (see research pitfall 2)
- Retry up to `max_retries` with exponential backoff
- `time.sleep(rate_limit_delay)` after each successful query (~2 queries/sec)
- On final failure: return `[{"status": "not_queried", "catalog": "ned", "error": str(e)}]`
- On success: convert to list of dicts with keys: `catalog_source_id` (Object Name), `object_type` (Type), `ra_deg`, `dec_deg`, `angular_separation_arcsec`, `redshift` (Velocity/Redshift), `raw_response`

**pipeline/catalog_clients/sdss_client.py:**

Create `query_sdss_region(coordinate: SkyCoord, radius_arcsec: float, max_retries: int = 3) -> list[dict]`:
- Use `astroquery.sdss.SDSS.query_region(coordinate, radius=min(radius_arcsec, 180.0) * u.arcsec, spectro=True, ...)`
- CAP radius at 180 arcsec (3 arcmin) per SDSS hard limit (research pitfall 3)
- Request `photoobj_fields=['objid', 'ra', 'dec', 'type', 'petroMag_r', 'petroMag_g', 'petroMag_i']`

- Retry with backoff
- On success: convert to list of dicts with keys: `catalog_source_id` (objid as str), `object_type` (type: 3=galaxy, 6=star), `spectral_class`, `spectral_subclass`, `ra_deg`, `dec_deg`, `angular_separation_arcsec`, `magnitude` (petroMag_r), `redshift` (z), `raw_response`

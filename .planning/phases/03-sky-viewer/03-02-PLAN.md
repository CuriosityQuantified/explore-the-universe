**Create `web/src/lib/wcs.ts`** -- TAN gnomonic deprojection:
- Import `WcsParams` from `../types/observation`
- Export `pixelToRaDec(pixelX: number, pixelY: number, wcs: WcsParams): { ra: number; dec: number }`
- Implementation follows the research pattern (Calabretta & Greisen 2002 TAN projection):
  1. Compute pixel offset from reference pixel: `dx = pixelX - wcs.crpix1`, `dy = pixelY - wcs.crpix2`
  2. Apply CD matrix: `xi = cd1_1*dx + cd1_2*dy`, `eta = cd2_1*dx + cd2_2*dy` (both in degrees)
  3. Convert to radians for trig
  4. TAN deprojection: compute `rTheta = sqrt(xi^2 + eta^2)`, `c = atan(rTheta)`, then standard formulas for RA/Dec
  5. Handle `rTheta === 0` case (returns crval1, crval2 directly)
  6. Normalize RA to [0, 360)
- This is ~40 lines of pure math, no external dependencies

**Create `web/src/lib/coordinates.ts`** -- formatting utilities:
- Export `decimalDegreesToHms(degrees: number): string` -- converts RA degrees to `XXh XXm XX.Xs` format (divide by 15 first)
- Export `decimalDegreesToDms(degrees: number): string` -- converts Dec degrees to `+/-XXd XXm XX.Xs` format
- Export `formatCoordinates(ra: number, dec: number, mode: "hms" | "decimal"): string` -- returns formatted string based on mode
- HMS format: `05h 35m 17.3s, -05d 23m 28.1s`
- Decimal format: `83.822d, -5.391d` (3 decimal places)

  <action>
Create `api/routers/tiles.py` with `router = APIRouter(prefix="/api/tiles", tags=["tiles"])` containing three endpoints:

**1. GET /{observation_uuid}/{level}/{col}_{row}.jpg** -- Tile proxy
- Streams tile JPEG from MinIO `tiles` bucket using `get_s3_client()`
- S3 key: `{observation_uuid}/tiles/{level}/{col}_{row}.jpg` (matches the key structure in `pipeline/tasks/tile.py` `_upload_tiles_to_minio`)
- Return `StreamingResponse` with `media_type="image/jpeg"` and `Cache-Control: public, max-age=31536000, immutable`
- On `NoSuchKey` / `ClientError` from boto3, return 404

**2. GET /{observation_uuid}/wcs** -- WCS parameter extraction
- Find the first FITS file in MinIO `fits-raw` bucket under prefix `{observation_uuid}/` using `list_objects_v2(MaxKeys=1)`
- Download to a temp file, open with `astropy.io.fits.open(memmap=True, mode="denywrite")`
- Find SCI extension: try `hdul["SCI"]`, fall back to `hdul[0]`, scan all extensions (same pattern as `pipeline/tasks/tile.py` `_find_sci_extension`)
- Create `astropy.wcs.WCS(header)`, call `.celestial` if `naxis > 2`
- Extract from `wcs_obj.to_header()`: CRPIX1, CRPIX2, CRVAL1, CRVAL2, CD1_1, CD1_2, CD2_1, CD2_2, CTYPE1, CTYPE2
- For CD matrix: fall back to CDELT1/CDELT2 if CD keywords are missing (some older FITS use CDELT instead of CD)
- Also read NAXIS1, NAXIS2 from the original science header (not the WCS-reduced header)
- Return JSON dict with keys: crpix1, crpix2, crval1, crval2, cd1_1, cd1_2, cd2_1, cd2_2, ctype1, ctype2, naxis1, naxis2
- Clean up temp file in `finally` block
- On missing FITS: return 404

**3. GET /{observation_uuid}** -- Observation detail
- Accept `db: Session = Depends(get_database_session)` (same pattern as ingest.py)
- Query `Observation` by `observation_uuid`
- Query `ProcessingStep` where `step_name == "generate_tiles"` and `step_status == StepStatus.completed` for tile metadata
- Return JSON with observation fields: observation_uuid, archive_observation_id, telescope_name, instrument_name, spectral_filters, total_exposure_seconds, pointing_ra_degrees, pointing_dec_degrees, pipeline_status, ingested_at, plus `tile_metadata` from the step's `step_output_metadata` (or null)
- On missing observation: return 404

**Register router** in `api/main.py`: add `from api.routers.tiles import router as tiles_router` and `app.include_router(tiles_router)`.

Use Pydantic response models for the WCS and observation detail endpoints (not the tile proxy -- it returns raw bytes). Follow the existing code style in `api/routers/ingest.py` (Depends injection, HTTPException for errors).

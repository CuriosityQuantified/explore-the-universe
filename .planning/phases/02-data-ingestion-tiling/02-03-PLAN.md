  <action>
1. Create `pipeline/tasks/ingest.py` — the Celery task that orchestrates the full pipeline:
   - Signature: `ingest_observation(archive_observation_id: str, archive_program_id: str | None = None) -> dict`
   - This is the entry point task that creates the Observation record and kicks off the chain

   Implementation:
   a. Create a SQLAlchemy session (SessionLocal from api.db.session)
   b. Create an Observation record in PostgreSQL:
      - `archive_observation_id` = provided obs ID
      - `archive_program_id` = provided program ID (nullable)
      - `telescope_name` = "JWST" (known at trigger time)
      - `instrument_name` = "UNKNOWN" (updated by download task from MAST metadata)
      - `pipeline_status` = PipelineStatus.downloading
   c. Commit and get the generated `observation_uuid`
   d. Build the Celery chain:
      ```python
      from celery import chain
      from pipeline.tasks.download import download_fits
      from pipeline.tasks.validate_wcs import validate_wcs
      from pipeline.tasks.tile import generate_tiles

      pipeline = chain(
          download_fits.s(str(observation_uuid), archive_observation_id, archive_program_id),
          validate_wcs.s(),
          generate_tiles.s(),
      )
      result = pipeline.apply_async()
      ```
   e. Return: `{"observation_uuid": str(observation_uuid), "celery_task_id": result.id, "status": "pipeline_started"}`

2. Create `api/routers/ingest.py` with two endpoints:

   **POST /api/ingest** — Trigger ingestion
   - Request body (Pydantic model `IngestRequest`):
     * `archive_observation_id: str` (required) — The JWST observation ID (e.g., "jw01073001001_02101_00001_nrca1")
     * `archive_program_id: str | None = None` — Optional JWST program ID (e.g., "1073")
   - Calls `ingest_observation.delay(archive_observation_id, archive_program_id)`
   - Returns 202 Accepted with response body (Pydantic model `IngestResponse`):
     * `observation_uuid: str`
     * `status: str` = "pipeline_started"
     * `message: str` = "Ingestion pipeline started. Use GET /api/ingest/{observation_uuid}/status to check progress."

   **GET /api/ingest/{observation_uuid}/status** — Check pipeline status
   - Query Observation record by UUID
   - Query all ProcessingStep records for this observation, ordered by step_started_at
   - Return 200 with response body (Pydantic model `IngestStatusResponse`):
     * `observation_uuid: str`
     * `archive_observation_id: str`
     * `pipeline_status: str`
     * `steps: list[dict]` — Each step: {step_name, step_status, step_started_at, step_completed_at, error_message_text}
     * `provenance: dict | None` — {telescope_name, instrument_name, spectral_filters, total_exposure_seconds, pointing_ra_degrees, pointing_dec_degrees}
   - Return 404 if observation_uuid not found

3. Update `api/main.py`:
   - Import and include the ingest router: `from api.routers.ingest import router as ingest_router`
   - `app.include_router(ingest_router)`

4. Update `pipeline/celery_app.py`:
   - Add `"pipeline.tasks.ingest"` to the include= list (if not already present from prior plans)
